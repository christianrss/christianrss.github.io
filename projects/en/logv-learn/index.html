LOGV Learn

Web learning platform for course content, student progress and enrollment.

Portfolio

Architecture

LOGV Learn is a web application organized around course management, learner activity and commercial enrollment.

  • Course management: courses, modules, lessons and publication of educational content.
  • Learning interface: content playback and records of student progress.
  • Identity: user accounts and authenticated access.
  • Enrollment: purchase and payment-related application flows.
  • Persistence: relational models for course information, users and enrollment state.

The course administration and learner-facing experience share application services and persistent data.

Technologies

  • Application: Next.js, React, TypeScript.
  • Database: PostgreSQL and Prisma.
  • Authentication: Clerk.
  • Content editing and playback: TipTap and Vidstack.
  • Payments: Asaas integration.
  • File storage integration: Amazon S3 SDK.
