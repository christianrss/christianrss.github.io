Mapa de sistemas

Uso projetos próprios como um laboratório vertical para compreender a computação de ponta a ponta, e não como demonstrações isoladas.

modelos → inferência → runtime de ML → toolchains / VMs → sistema operacional → hardware

  • Modelos — Chris-GPT-2: pré-treinamento, avaliação e reprodutibilidade.
  • Inferência — Chris-Llama: GGUF, tokenização, atenção, KV cache, quantização e execução CPU/GPU.
  • Runtime de ML — Chris-Torch: tensores, autograd, componentes de redes neurais e backends acelerados.
  • Toolchains / VMs — experimentos de compilador, assembler, linker e máquina virtual desenvolvidos em torno do ChrisOS.
  • Sistema operacional — ChrisOS: kernel, memória, drivers, gráficos, filesystem e infraestrutura de baixo nível.
  • Hardware — engenharia elétrica, eletrônica e robótica como a camada física abaixo da pilha de software.

Minha atuação profissional fica acima e atravessa essa pilha: sistemas corporativos, APIs, aplicações desktop e web, software fiscal e de varejo, infraestrutura e ferramentas internas de engenharia.
